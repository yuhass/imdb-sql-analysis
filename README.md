# IMDb SQL Analysis

This project analyzes the IMDb Top 1000 Movies dataset using SQL Server.

The goal of this project is to practice SQL by answering 18 analytical questions about movie ratings, genres, directors, release years, votes, and certificates.

## Tools Used

- SQL Server
- SQL Server Management Studio (SSMS)
- GitHub

## Analysis Questions

The project answers questions such as:

- What are the 10 highest-rated movies?
- Which movies have the highest Metascores?
- How many movies are there for each certificate?
- What is the average IMDb rating by genre?
- Which directors have the highest average IMDb ratings?
- How has movie production changed across decades?
- Which movies have more than 1 million votes?
- Which movies are rated higher than the overall IMDb average?
- Which movies perform better than the average rating of their own genre?
